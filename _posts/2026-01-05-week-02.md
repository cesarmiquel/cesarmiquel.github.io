# Dittytoy: The Code-Driven Music Playground for the Web.

From the website: "Dittytoy is a platform for creating code-driven music using JavaScript. Instead of arranging samples on a timeline, you write code that generates sound. This lets you create music that evolves, responds to parameters, or never repeats. Everything runs in your browser using the Web Audio API "

# SEGA Genesis

![Sega Genesis Mod1](/assets/imgs/2026-01-05/Sega-Genesis-Mod1.jpg)

I have been gifted a SEGA Geneis game console so I'm excited to write some code for it. The exact model is the #MK-1601. Aparentely there are a couple of versions, I have the "Sonic" version. From an [article which talks about the different variations](https://gametrog.com/sega-genesis-1-2-3-information-specs): "This version looks the same as the original but SEGA added the License Screen that would pop-up before each game, adding about 3-4 seconds to your initial wait time to get to the gaming. Also, from this revision on SEGA installed a “Lock-Out” chip for regional restrictions. The FCC-ID code for this unit is: **FJ8USASEGA**."

In preparation for my next projects here are some resources on coding for the SEGA Genesis:

- [SGDK](https://github.com/Stephane-D/SGDK) - A free and open development kit for the Sega Mega Drive. "SGDK is a free development kit allowing development of software in C language for the Sega Mega Drive. It contains the development library itself (with the code sources) and some custom tools used to compile resources. SGDK uses the GCC compiler (m68k-elf target) and the libgcc to generate a ROM image. Binaries (GCC 13.2) are provided for Windows OS for convenience, but you need to install it by yourself for other operating systems (more infos about it in HELP AND SUPPORT section). Note that SGDK also requires Java (custom tools require it), so you need to have Java installed on your system."
- [SGDK Helper](https://github.com/tlsa/sgdk-helper) - Helper script for working with SGDK on Linux. This helper is really cool because you can develop having all your tools inside a Docker container. Probably will go with this option.
- [Docker SGDK](https://gitlab.com/doragasu/docker-sgdk) - Docker container to build SGDK stuff
- [Awesome Mega Drive Development](https://github.com/And-0/awesome-megadrive) - A curated list of Sega Mega Drive development resources
- [Mega Cat Studios Blog](https://megacatstudios.com/pages/blog) - A cool blog with several interesting articles as they are SEGA Genesis developers.
- [4000 in 1 MD V3 Pro Card With 8GB TF Card MD Game Card For SEGA Genesis Mega Drive Master System Game Console](https://es.aliexpress.com/item/1005008228502861.html)- I bought this card to use on my SEGA Genesis to be able to upload my homebrew games.

# REST in Neovim

As most developers now a days I need to test REST APIs. Most developers use Postman. Personally it annoys me to have to log in to an application to do this. I prefer to use CLI tools. As a vim user I learned about the `rest.nvim` pluing for Neovim. You basically create a simple `.http` file for where you can store your server requests in text format. For more information on the `http` format see [this page](https://www.jetbrains.com/help/idea/exploring-http-syntax.html) on the IntelliJ editor page.

- [Pluing page - rest.nvim](https://github.com/rest-nvim/rest.nvim) - GH page: "A very fast, powerful, extensible and asynchronous Neovim HTTP client written in Lua."
