# Shadertoy resources

I've been looking a little more into Shadertoy and found some useful resources.

- [Shadertoy Unofficial](https://shadertoyunofficial.wordpress.com/) - This blog has lots of cool resources. Most of the following interesting bits I found there.
- [Distance field outline mask](https://www.shadertoy.com/view/XtG3Rt) - This example shows how to draw a bezier curve and other simple 2D paths.
- [Programming tricks in Shadertoy / GLSL](https://shadertoyunofficial.wordpress.com/2019/01/02/programming-tricks-in-shadertoy-glsl/) - Tips like: Drawing thick lines, Antialiasing,  Drawing lines, Blending / compositing
, etc
- [Commodore 64 simulator](https://www.shadertoy.com/view/Xs3XW4) - A simulation of a C64
- [iResolution, iMouse, iDate, etc](https://www.shadertoy.com/view/llySRh) - iResolution, iMouse, iDate, etc in GLSL. Drawing text.
- [The Book of Shaders](https://thebookofshaders.com/) - Some nice tricks and resources here.

# Magazine archive

![Zoomable Byte Magazine Archive screenshot](/assets/imgs/2025-09-15/byte-archive.png)

- [Zoomable Byte Magazine Archive](https://byte.tsundoku.io/) - This is an awesome and very fast archive of **all** issues of Byte magazine. From the site: "This zoomable map shows every page of every issue of BYTE starting from the front cover of the first issue (top left) to the last page of the final edition (bottom right). The search bar runs RE2 regex over the full text of all 100k pages. The archive itself is not new, scans of BYTE have long existed on the Internet Archive and elsewhere on the net – but I hope seeing everything in single, searchable place offers a unique perspective."
- [VintageApple.org](https://vintageapple.org) - Another archive with scanned issues of Byte, PC World Magazine, Macworld, Macuser, and many other Apple related books and manuals.

# Nanogems

As you know by know I am a fan of sizecoding. There is a site called **Nanogems** where you can find some cool examples of sizecoding. Some have source code so here are some of the ones I liked:

![Kacifantos screenshot](/assets/imgs/2025-09-15/kacifantos.jpg)

- [Kacifántos creatures in a chaotic dream by TomCat / Abaddon](https://demozoo.org/graphics/318968/) - [Pouet entry](https://www.pouet.net/prod.php?which=93549) There are two versions with the assembler code.

![Screenshot of Seeing the light ...](/assets/imgs/2025-09-15/stlateott.jpg)

- [Seeing The Light At The End Of The Tunnel](https://demozoo.org/productions/202652/) - [Pouet entry](https://www.pouet.net/prod.php?which=81004). Has source code. [YouTube](https://www.youtube.com/watch?v=LPJl1C8Gr8k) This entry is really remarkable. Need to understand the source code.

![Screenshot of Remnants ...](/assets/imgs/2025-09-15/remnants.png)

- [Remnants](https://demozoo.org/productions/342211/) - This is a pretty remarkable entry. [Pouet entry](https://www.pouet.net/prod.php?which=96536) It has [source code](https://www.dominik-ries.de/files/download/remnants.asm) and is based off [this shadertoy entry](https://www.shadertoy.com/view/cd3GWf)

![Shiftride screenshot](/assets/imgs/2025-09-15/shiftride.png)

- [Shiftride](https://demozoo.org/productions/308605/) - 128b MSDOS.

- [Downtown](https://demozoo.org/graphics/367619/) - Procedural generated graphics for ZX spectrum. [Shader source code](https://www.shadertoy.com/view/W3l3Wr)

![Drinking Fountain](/assets/imgs/2025-09-15/drinking.png)

- [Drinking Fountain](https://www.pouet.net/prod.php?which=96016) - 256b MSDOS procedural graphics. No source code but has [Shader source code](https://www.shadertoy.com/view/X3sGRB)

![Screenshot](/assets/imgs/2025-09-15/tdlid.png)

- [The Dick Laurent is Dead](https://demozoo.org/graphics/367620/) - 256b for ZX spectrum procedural graphics. Really cool but without source. Made by [jokerteam.pl](https://jokerteam.pl/). Many cool procedural images there.

![Monospace screenshot](/assets/imgs/2025-09-15/monospace.jpg)
