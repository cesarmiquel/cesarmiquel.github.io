# Guitar effects and amp modeling

For my guitar setup I've been using [Guitarix](https://github.com/brummer10/guitarix) on my laptop to simulate effects and amps. Recently I started seeing lots of references to 'Neural' in regards to guitar effects and amp modeling (Neuraldsp / Neural Amp Modeler) so I decided to see whats this all about. It turns out you can train a Neural network to simulate the behavior of a guitar amp and effects. The idea seems to be to create a clean tone with several variations, pass that clean tone through a real amp and effects setup and train a Neural network to learn the behavior of the real setup. In this way you can have different network networks that simulta different setups which you can later combine.

### Links 🔗

- [NEURAL AMP MODELER](https://www.neuralampmodeler.com/) - Neural Amp Modeler is an open-source project that uses deep learning to create models of guitar amplifiers and pedals with state-of-the-art accuracy.
- [History of NAM](https://www.neuralampmodeler.com/post/the-history-of-nam)
- **NAM Source Code** - The NAM has 3 components:
  - [NAM-Training](https://github.com/sdatkinson/neural-amp-modeler) - This repository holds the machine learning code used to make new models.
  - [Core DSP](https://github.com/sdatkinson/NeuralAmpModelerCore) - This repository contains the low-level DSP code for playing NAM models in real time.
  - [Plugin](https://github.com/sdatkinson/NeuralAmpModelerPlugin) - This repository integrates the core DSP with the iPlug2 framework to create plugins (VST3, AU) and a standalone desktop application.
- [Neural Amp Modeler LV2 GUI](https://github.com/brummer10/neural-amp-modeler-ui) - This is a Gui for the Neural Amp Modeler LV2 plugin by Mike Oliphant
- [Tonehunt models](https://tonehunt.org/) - Share your models with other NAM users and find others' models on ToneHunt, a community-organized online library.
- [NAM for users](https://www.neuralampmodeler.com/users) - Here you'll find everything you need to get into NAM, from making your own models to getting connected with tens of thousands of other musicians enjoying NAM.
- [Neural Amp Modeler - Model Training Notebook](https://colab.research.google.com/github/sdatkinson/NAMTrainerColab/blob/main/notebook.ipynb#scrollTo=5CQleTk7GJV8) - A Google Colab notebook to train a model via NAM.
- [LV2](https://lv2plug.in/) - LV2 is an extensible open standard for audio plugins. LV2 has a simple core interface, which is accompanied by extensions that add more advanced functionality.
- [LV2 projects](https://lv2plug.in/pages/projects.html) - This page is a partial list of LV2 projects. If you know of any that are not listed here, please let us know or send a patch.
- [Ratatouille](https://github.com/brummer10/Ratatouille.lv2) - Ratatouille is a Neural Model loader and mixer for Linux/Windows. It can load two models, which can be *.nam files with the Neural Amp Modeler module, or *.json or .aidax files with the RTNeural module.

What really look super interesting is the **MOD Desktop** tool. It is a webapp (that runs locally) that allows you to wire  LV2 plugins together to create a custom guitar effects chain. Here's a recent screentho and the link to the [MOD Desktop in Github](https://github.com/mod-audio/mod-desktop).
